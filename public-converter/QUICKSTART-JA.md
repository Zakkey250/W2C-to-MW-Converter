# W2C to MW Converter 2.0.0 — 初回利用ガイド

**コンバーターRC6.1（Windows x64）。** ZIPをすべて展開し、`_internal` フォルダーを隣に置いたまま `W2C-to-MW-Converter.exe` を起動してください。初めて変換するときは原本読み込み部品のセットアップを確認してください。必要な部品をネットから取得・照合し、PC内でビルドします。PythonやVisual Studioは不要です。

RC5以前の環境へRC6の変更をすべて反映するには、W2Cの原本から再構築してください。最初のW2C導入時に退避した原本は保持されます。

### 用意するもの

- [W2C 2.0.0](https://nfsmods.xyz/mod/3041) を展開したフォルダー。
- Need for Speed Most Wanted (2005) のゲームフォルダーと、対応する **32ビット MW 1.3 LAA** の `speed.exe`。NFSPatcher製とRedux 3.04同梱版で確認した実行構造を検査します。
- [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/tag/v10.0.4) の32ビット `dinput8.dll` と [DirectXランタイム](https://www.microsoft.com/en-us/download/details.aspx?id=8109)（`d3dx9_43.dll`）。確認済みの6.4.0・10.0.2・10.0.4のビルドは、検査画面にバージョンが表示されます。
- 出力先ドライブに 62 GiB 以上の空き。変換中は中間データを作り、処理後は自動で片付けます。

導入先のワールド資源が変更されている場合は「純正MWの参考元」に別の未改造フォルダーを指定します。車両フォルダー・属性ファイル・セーブを保持し、変更済みのワールド資源を退避します。同梱のロールバッカーで導入前の版に戻せます。

Redux 3.04は検証済みの同梱 `speed.exe` と `dinput8.dll` を使用できます。Reduxを複製するときは、同梱の NextGenGraphics、Custom Shaders、シェーダーと画像資源もそろえてください。不足がある場合は検査画面に表示します。

### 変換する

1. **原本を選択**：W2Cの展開先とMWの導入先を指定し、`NORMAL`、`WORLD`、`X360` から原本の品質を選びます。
2. **導入先を検査**：不足している項目や競合が表示された場合は案内に沿って対処し、再検査してください。
3. **変更内容を確認**：新しい出力フォルダーを指定します。そのまま遊ぶ場合は「自動配置」を選び、ゲームを終了してから進みます。
4. **ローカル変換を開始**：「配置が完了しました」と表示されたら、MWの `speed.exe` から起動してください。「保存しました（未配置）」の場合はゲームに反映されていません。完了画面の「このパックを配置」か、最初の画面の「変換済みパックを配置」から適用できます。

パックをゲームフォルダーへ手動でコピーしただけでは、W2Cワールドは読み込まれません。すでにコピーした場合は、導入先を指定して「変換済みパックを配置」を押し、「コピー済みのパックを検出」で「はい」を選んでください。ファイルを照合し、再変換せずに配置します。

ワールドマップとレーダーはW2C原本を使います。Carbonのゲームフォルダーを指定すると、照合できた原本から、W2C原本にない夜空・ヘッドライトの発光・窓の反射などのテクスチャを補います。CarbonはOGVIが指定済みでも空欄のまま進めます。W2CとMWの原本だけで変換でき、MWやCarbonの資源は言語を問わず読み取れるものを使います。

### Carbonのパースートブレーカーを復元する

Carbonのゲームフォルダーと、Attribulator 2.0にOGVI 1.4を重ねて展開したフォルダーを指定します。対応するCarbon原本から破片、専用カメラ、爆発などの追跡演出を再生成します。専用カメラの再生には、警察の追跡中にブレーカーを作動させ、ゲーム側でカメラ演出を有効にしておく必要があります。[Attribulator 2.0](https://github.com/NFSTools/Attribulator/releases/tag/v2.0.0) · [OGVI 1.4](https://nfsmods.xyz/mod/5290)

CarbonにW2Cの小物属性が入っていない場合は、W2C 2.0.0原本のスクリプトから、変換に必要な属性を作業フォルダーで補います。Carbonへの事前適用は不要です。

復元に必要な物理属性は、変換時点の導入先をもとにパック内に生成します。ゲームは `GLOBAL/attributes.bin` などの原本を通常どおり読み、W2C専用の追加分はワールドに入るときにだけメモリに登録します。車両追加などで変換後にMWの属性データを編集した場合は、その導入先を指定して再変換してください。

以前のプレビューで作ったパックは「変換済みパックを配置」から引き続き使えます。パースートブレーカーの効果範囲や交通規制材の復元を反映するには、W2C原本から再変換してください。

### RC6の追加コンポーネント

変更内容の確認画面に「Addonのインストール」「LBx64 RC3.1をインストール」「NFSMWVCacheAffinityをインストール」から必要な項目を選べます。Addonは **W2C 未開通区間の暫定開通** です。道路追加とモデル配置の変更を、選択した品質とCarbonの有無に合わせて準備します。Addonを選ばなくても、通常の地形・照明・トンネル内降水などの修正は有効です。

未選択のコンポーネントも変換パックの `Optional`、配置後はゲーム内の `W2CMWPublic/Optional` に導入ガイド付きで保存します。後から導入する場合も、コンバーターの「変換済みパックを配置」から必要な項目を選ぶ方法を推奨します。

LBx64を選んだ場合は、旧LBと読み込み先に重複するLBを退避して差し替えます。退避先はASIの探索対象外です。復元時は、旧LBと既存設定も戻します。RC5以前へ導入した際の原本バックアップは更新で上書きしません。復元後は、最初のW2C導入前のワールドに戻ります。

LBx64は対応するNFSPatcher EN-US 1.3とRedux 3.04に自動配置できます。ReduxではNextGenGraphicsと同梱シェーダーを保持します。描画方式の指定がまだない場合はDX11で始まります。標準DX9、DX9Ex（FlipEx）、DX11、DX12の切り替えは同梱のLBx64ガイドを参照してください。DLSS・DLAAには対応するNVIDIA GPU・ドライバー・SunSetが必要です。

NFSMWVCacheAffinityはL3容量が異なるCCDを持つAMD Ryzen X3Dと対応する英語版1.3向けです。対応CPUではゲームを3D V-Cache側に割り当てます。設定は `scripts/NFSMWVCacheAffinity.ini` にあります。Reduxではこの項目をオフにしてください。

### SunSetの自動セットアップ

W2Cの昼夜サイクル、天候、照明、ワールドの影を再現するため、SunSetを推奨します。未導入のままでも、MWの標準描画で変換・配置できます。SunSetを使う場合はTexWizardと描画資源が必須です。不足したままではフリーランへの切り替えでゲームが終了することがあるため、コンバーターは配置を止めます。

1. [SunSet 1.15.2の公式ZIP](https://nfsmods.xyz/mod/6659) と [TexWizard 1.3の `TexWizard_MW.zip`](https://github.com/R-033/texwizard/releases/tag/1.3) を各配布元から入手します。コンバーターには同梱していません。
2. 検査画面から「SunSet・TexWizardを自動セットアップ」を開き、ZIPを指定します。すでに検査に通る構成のMODは指定を省けます。
3. ゲームを終了し、「不足分を配置」を押します。新規導入には白飛びを抑えたW2C用設定を使います。導入済みのSunSetに同じBloom設定を適用する場合は、画面のチェックを入れてください。TexWizardの自動スキャンがOFFの場合は、既存の一覧にSunSetのパック参照を追加します。「中断した配置を復元」で途中で止まった操作を取り消せます。

夜間の建物照明を復元するには、SunSetのセットアップを済ませてからW2C原本を変換してください。導入先のSunSetにある発光マスクを変換時に参照し、窓の発光は夜間だけ有効になります。以前のプレビューで変換したパックには再変換が必要です。

SunSetのZIP内の `exhaust.nfsms` は排気演出を追加する別オプションです。料金所や小物の復元に対応する前のプレビューで作ったパックは、W2C原本から再変換してください。

同梱の推奨設定を使う場合は、ゲームを終了し、既存の `scripts/SunSetData/Config.yml` を退避してください。検査画面の「SunSetの推奨設定を開く」から `Config.yml` を選び、その場所にコピーします。この操作は任意です。SunSet本体、シェーダー、テクスチャは各配布元から導入してください。

日中のワールドの影を表示するには、MWの画面設定で「Shadow Detail（影の詳細）」を有効にしてください。同梱のSunSet設定では夜間の影を無効にしています。動く小物自身が路面に落とす影は未対応です。

### 再現できる範囲

変換の完了画面に、元のモデルやテクスチャが見つからない件数と、再現できていない機能を表示します。

- Carbonなしでは、モデル・当たり判定・物理設定がMW原本と一致する小物や装置を動くオブジェクトとして復元します。外観のみ再現した小物と動的に復元できなかった配置の件数は、完了画面に表示します。
- Carbonなしの場合、給油機は元の設置位置にMW純正のモデルと爆発処理を使って復元します。ガソリンスタンドやタイヤ店の支柱・屋根は、対応するMWの構造があればそれを使い、対応しない部品はW2C原本の外観を残します。
- パルモントの共用施設では Home キーでセーフハウスとショップを切り替え、ゲームの決定操作で入場します。追跡のクールダウン中はセーフハウスを利用できます。
- MW原本のワールドに戻すには、ゲームを終了し、ゲームフォルダーの `W2CMWPublic/W2CMW-Rollback.exe` を開いて確認してください。セーブ、変換済みパック、SunSet、TexWizardは保持されます。
- Rockportの料金所、遮断機、標識は導入先にあるMWの原本から復元します。Carbonを用意する必要はありません。
- Carbon原本とOGVIを指定しない場合、Carbon固有のパースートブレーカー、その追跡用マーカーと専用カメラは省略されます。パルモントではゲームの言語に合わせて市名を表示します。
- Carbon原本とOGVIを指定すると、パルモントの地名表示を原本の縄張りデータに沿った22地区に分けます。日本語と英語のほか、MWのフランス語、ドイツ語、イタリア語、スペイン語、オランダ語、スウェーデン語、デンマーク語、ポーランド語、フィンランド語の地域表記に対応します。
- ロックポートとパルモントの地名の切り替えには、照合済みの道路座標を使います。Need for Speed Worldのインストールは不要です。
- ワールドのアニメーションと環境エフェクトはW2C原本の配置から復元します。対応するCarbon原本とOGVIを指定するとCarbonのエフェクトを再現し、指定しない場合はMWのエフェクトを使います。対応する資源がない種類と、代替した配置の件数は完了画面で確認できます。
- 最初の画面の右上で、コンバーターの表示言語を17種類から選べます。保存や配置が完了したら「閉じる」で終了できます。アンインストーラーにも表示言語の切り替えがあります。

導入先検査には [Unlimiter](https://github.com/nlgxzef/NFSMWUnlimiter/releases) と [Extra Options](https://github.com/ExOptsTeam/NFSMWExOpts/releases) の検出状況も表示します。どちらも基本構成の必須MODではありません。コンバーターはこれらの設定を書き換えません。

配置処理は標準セーブと `GLOBAL/attributes.bin`、`fe_attrib.bin`、`gameplay.bin`、`gameplay.lzc` を書き換えません。配置先で変更するゲーム資産は `W2CMWPublic/originals` と `W2CMWPublic/rollback` に退避します。配置が途中で止まった場合は、同じ導入先の検査画面から「中断した配置を復元」を選んでください。既存MODの設定変更が必要な場合は検査結果の案内に従ってください。

「32ビットの `dinput8.dll` を検出しましたが、検証済みビルドと一致しません」と表示された場合も、配置先の原本資源が適合すれば変換済みパックを保存できます。自動配置する場合は、別のゲームフォルダーに対応ローダーを用意して再検査してください。ローダーの導入は手動で行います。
