# W2C to MW 2.0.0 Converter RC6.1

The bundled LBx64 supports native DX9, DX9Ex (FlipEx), DX11 and DX12. The updated converter can also install this complete LBx64 component with packs generated by the original RC6.

Automatic LBx64 installation now supports the verified Redux 3.04 executable. It preserves NextGenGraphics and the shader files. DX11 is the Redux default when there is no existing renderer setting.

This update follows RC5. The required source release remains **W2C 2.0.0**. Rebuild your world with this converter to include the changes below.

## Palmont rendering update

- Reduces repeated terrain material lookups and emissive texture setup, including near Infinity Park. Terrain draw order, LOD, culling, lighting and weather settings are preserved. New conversions and installations use the updated W2C runtime. Existing RC6-generated packs can be reused after the installer verifies their hashes.

## New optional components

- **W2C provisional access to unopened roads Addon** opens previously inaccessible routes and adjusts object placement along them. The converter prepares the Addon for NORMAL, WORLD or X360 and the selected Carbon resources. The routes are provided as a preview.
- **LBx64 W2CtoMW RC3.1** includes expanded vehicle and vehicle-resource limits, a 64-bit resource host, and components for DLSS and DLAA on compatible systems. Select its installation in the converter. DLSS and DLAA require a supported NVIDIA GPU, driver and SunSet.
- **NFSMWVCacheAffinity 0.7.1** is an optional component for AMD Ryzen X3D CPUs with different L3 cache sizes across CCDs. It assigns the game to the 3D V-Cache CCD. With LBx64, it moves the resource host and DLSS worker detected at startup to the higher-clocked CCD.
- Unselected components are still saved with installation guides in the converted pack's `Optional` folder. Installing the pack also places them in `W2CMWPublic/Optional`.

## Changes since RC5

- Improved daytime tunnel lighting and suppression of precipitation inside tunnels.
- Fixed invisible winter terrain collision remaining on the Rockport golf course and the collision that could lift a car near the bus terminal.
- Improved world loading and rendering.
- Ordinary terrain, lighting, precipitation and road fixes apply with the Addon disabled. Only provisional access to unopened roads depends on the Addon option.
- Installing LBx64 retires the old LB and duplicate LB modules from loader search paths. The old files and existing settings are protected for restoration by the included rollback utility.
- Upgrading an RC5 or earlier installation preserves the original world backups made before W2C was first installed. They are not replaced with the previously installed W2C world.

## Updating and compatibility

1. Close the game and launcher, then rebuild from your W2C 2.0.0 source with Converter RC6. You can select an existing W2C game folder.
2. Choose any of the Addon, LBx64, and NFSMWVCacheAffinity installation options you want, review the checks, and install.
3. To restore the original environment, close the game and run `W2CMWPublic/W2CMW-Rollback.exe`. Saved games, vehicle files, attribute data and control bindings are outside this update.

NFSMWVCacheAffinity requires a compatible EN-US 1.3 executable. Leave that option off when installing on Redux.

DLSS at 100% and DLAA were verified at 3840×1600 on a GeForce RTX 5070 Ti with NVIDIA driver 621.24.
DLSS Performance (50%) and DLAA were verified at 1920×1080 on a GeForce RTX 2070 SUPER with NVIDIA driver 621.24.

Known issues remain: some stock MW events have checkpoints that cannot be crossed normally, and loading can occasionally take a long time. Compatibility with every other mod combination is not guaranteed.
